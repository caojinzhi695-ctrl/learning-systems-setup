# Manim 复习视频模块

从已完成AI笔记的notes字段取材，通过已配置DeepSeek填入原片版式库，使用本地Manim0.22渲染1080p MP4。入口在总结笔记的收集栏旁。

视觉基准：用户提供《01-Manim-新手选品-50秒快复习.mp4》。原内容复刻1500帧SSIM=1.000000，原始代码几何/字体/动画保持一致。

新版由 exact_video_plan.py 校验、manim_exact_scene.py 绘制。quick_review_v1 包含完整示例、逐槽说明、DeepSeek提示词、schema、配乐和可独立运行的render.py。具体说明见该目录README.md。

固定字体和版式，不卡死视频时长：DeepSeek选择2—24页、每页4—14秒，总长最多240秒；八卡回忆页至少6秒。summary解释覆盖范围，UI显示程序加总的真实时长。过长内容可拆主题。新内容不必复用全部8种版式。

校验失败保留草稿，最多进行一次带校验反馈的模型修正；仍失败则停止，网络失败不自动重试；重新渲染只复用保存分镜，不再次调用AI。每页引文必须能匹配AI笔记，不能把引用校验当作全部改写内容的事实保证。

模板仅接收文本数据，AI不能提交Python或样式。渲染子进程不接收API密钥；输出视频、分镜和源码包保存在用户运行目录。旧版视频仍可播放和用旧渲染器重新生成。

测试：tests/api/test_summary_videos.py；web/tests/manim-review-video.spec.tsx。实际广告笔记测试经过人工内容核对，DeepSeek选择6页44秒。

## 两步生成流程 v2
第一步DeepSeek只接收编号原文片段，分析核心问题、重点、条件与关系，输出review_brief。第二步只接收复习稿与所选依据，不接收整篇notes，按复习稿编排画面与时长。引用由程序按编号从原文提取。
复习稿保存且可在界面展开。通常两次模型请求，第二步最多修正一次，单次生成最多三次请求；连接错误不自动重试。第一步已完成但分镜失败时，可继续制作分镜，复用与原笔记哈希匹配的复习稿。修改原笔记后不能复用旧稿。
提示词：video_brief.py；便于阅读的导出：quick_review_v1/NOTE_TO_REVIEW_PROMPT.md。源码包同时含review-brief.json。

## 内容与排版解耦 v3
所有AI步骤仅调用用户配置的DeepSeek。启用官方JSON Output。第一步整理复习稿；第二步仅输出标题、2—6张语义卡片、条件、引用编号和时长，不再输出body_XX。Pydantic验证语义结构，绘制代码自动选择行列、换行及可选区块。
缺少可选副标题、脚注或提示栏不会导致结构失败。不编造缺失知识，不裁掉超长正文。字号、配色仍采用原片；原版历史视频继续使用原版渲染器。
推理发生在DeepSeek API，画面绘制与MP4封装发生在本地Manim/FFmpeg。DeepSeek官方Tool Calls文档明确，函数由调用方执行，模型不执行函数本身。
参考：Instructor的schema-first与校验反馈、LangGraph的分阶段持久化、AIManim的规划/渲染/修复分层。沿用项目已有Pydantic和任务状态，不新增庞大框架依赖。

## 原片字体与颜色
样式配置：quick_review_v1/typography.json。微软雅黑；主标题39深蓝#253B52，卡片标题26/28蓝#3466E8，数值52蓝，普通文字结论36深蓝（窄卡28），说明20/22灰#7E8DA2，脚注13灰，提醒橙#C88648。密集网格标题28、次级文字22灰。正文根据实际宽度换行，必要时有限适配，不改变字体族。
