## DeepSeek 能改什么

example.json 是逐字复刻原片的完整示例。每页 duration 为总秒数；texts.title/subtitle/caption/note 分别对应标题、副标题、蓝色底栏、脚注；body_01 开始按上表顺序填写。
模型可以从8种版式中选择、重复、调整顺序，并设置每页 duration（4—14秒，overview至少6秒）；2—24页，总时长最多240秒。只改变内容、版式选择与停留时长，不改变所选版式的文字槽、字体或动画样式。
slots.json 给每个槽原文字样、字号、粗细、宽度和最大文字容量。max_units 按中文1、ASCII0.54计算，必须精简到容量内，不能靠缩小字号塞入长句。
DEEPSEEK_INSTRUCTIONS.md 与完整示例会随每次模型请求发送。exact_video_plan.py 校验所选版式、时长、全部槽、容量、禁止附加字段，并验证每页引用出自所选 AI 笔记。格式不合格保留草稿，最多调用模型修正一次；仍不合格停止。两步流程通常两次模型请求，分镜修正一次时最多三次，网络失败不自动重试。
引用匹配仅验证引文来源，不能保证模型每个改写都完全正确；查看分镜依据后可校对内容。
原片中的阈值仅是示例内容；换笔记时必须改为新笔记支持的结论，不能照搬50件、30%等数值。没有数字时填短结论。

## 代码和复现

应用内：manim_exact_scene.py 控制固定样式，exact_video_plan.py 控制模型契约，manim_render.py 执行渲染与配乐封装。旧任务仍由旧版渲染器处理。
下载源码包后：安装 Python 3.12、manim==0.22.0、imageio-ffmpeg、微软雅黑。运行 `python quick_review_v1/render.py`，输出 video.mp4。
storyboard.json 是当前任务内容；reference_story.json 是固定原版骨架；example.json 是模型填写示例。想复刻原内容时用 example.json 作为 storyboard.json。
更换内容无需编辑任何动画代码。改变模板样式应另建版本，不能让模型修改本版。

## 自动时长原则
不强制8页或50秒。DeepSeek按知识点数量、文字密度和复习用途判断，短句4—6秒、关系页6—8秒、密集页8—12秒，入场后保留阅读时间。summary解释覆盖范围与节奏。原例时长只用于复刻验证。

## 2026-10-28 排版容量修复
原示例的字数不能代表卡片容量。template_geometry.py按卡片宽度和字号计算预检容量；manim_exact_scene.py用真实微软雅黑字形宽度检查边界。能容纳的文字保持原字号；轻微超宽最多缩放10%，明显过长仍停止。原片相同文字沿用原渲染，原有视觉保持不变。

## 笔记整理与分镜分开
第一步只做笔记分析，提炼重点、关系、条件和自然短句。第二步只读取review_brief，不再一次性处理全部原文。原文证据用编号由程序提取。界面可查看复习稿，失败时可继续制作分镜复用它。完整提示词见NOTE_TO_REVIEW_PROMPT.md；源代码见video_brief.py。
