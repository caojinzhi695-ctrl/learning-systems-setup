# DeepSeek × Manim 复习视频（0.8.0）

本次定制的上游底版为 **DeepTutor v1.6.15**。它包含当前学习助手中的总结笔记、互动练习、思维导图、笔记导出，以及复习视频功能。

## 使用

1. 打开“总结笔记”，先完成一篇 AI 笔记。
2. 展开“收集栏”，点击这篇笔记灰色标题条右侧的 **生成视频**。
3. 面板自动选中该笔记，可填写复习重点，再点击“DeepSeek 自动设计并生成 Manim 视频”。
4. 查看第一步整理的复习稿，等待分镜与渲染完成，然后播放或下载 MP4、源码包。

打开制作面板只读取任务记录，不发送模型请求。点击制作才产生 API 用量。所有 AI 请求均使用你配置的 DeepSeek；Manim/FFmpeg 在本地渲染视频，不使用其他 AI 供应商。

流程为：原文片段编号 → DeepSeek 分析并整理复习稿 → DeepSeek 输出内容卡片及阅读时长 → 程序自动排版 → 本地 Manim/FFmpeg 输出 1080p MP4。

模型不再填写 `body_01` 等绘图内部字段。每页可以有2—6张卡片，可选副标题、脚注和提示栏可以省略。字体、颜色、位置和换行由代码处理。编号引用由程序从原笔记取回，不让模型改写成长引文。

## 安装与升级

新安装按仓库 README 执行。`Install` / `CustomizeNotes` 会安装笔记依赖，并创建独立环境：`DeepTutor-runtime/tools/manim/.venv`，安装 `manim==0.22.0` 与 `imageio-ffmpeg==0.6.0`。

Windows 需要系统已有的微软雅黑（Microsoft YaHei）。本仓库不重新分发该字体。

本版补丁严格匹配 v1.6.15 上游提交 `a31d82624c27d75f4e771d4fcb78dce16470b383`。已有 v1.6.14 安装应先备份，并按上游方式升级或另建 v1.6.15 安装；直接套用会被安装器拒绝。已有自定义修改的文件，只有精确匹配已知旧版哈希才允许备份升级；未知改动仍需手动合并。不要用本包覆盖个人数据。

## 配乐

公开仓库不包含个人视频、背景音乐或生成成片。没有本地配乐时正常导出无旁白、无配乐的 MP4。

要使用自己的配乐，在启动后端的环境中设置 `DEEPTUTOR_REVIEW_MUSIC` 为一个本地音频文件的绝对路径，然后重启后端。配乐文件不存在时会明确报错。源码下载包也支持同一设置。

## 样式与代码

- `deeptutor/services/summary_notes/video_brief.py`：第一步笔记分析提示词、引用编号与复习稿。
- `semantic_video_plan.py`：第二步内容卡片提示词、数据结构与校验。
- `manim_semantic_scene.py`：新版本的代码绘图、自动排版。
- `quick_review_v1/typography.json`：微软雅黑字号和配色，来源于用户指定参考片。
- `manim_render.py`：隔离运行、进度、取消、配乐和 MP4 封装。
- `deeptutor/api/routers/summary_videos.py`：持久化任务、分阶段调用及文件接口。
- `web/components/summary-notes/ManimReviewVideo.tsx`：制作面板。

默认样式为深蓝主标题39、蓝色卡片标题26—28、蓝色关键数字52、深蓝文字结论36（窄卡28）、灰色说明20—22、灰色脚注13，以及橙色提醒。数值是 Manim 字号，不是网页 CSS 像素。

## 费用与恢复

通常是两次 DeepSeek 请求：复习稿一次、分镜一次。分镜结构不合格最多修正一次，单次生成最多三次请求；网络失败不自动重试。模型输出和分阶段结果会保存。

第一步已完成但分镜失败时，可“继续制作分镜”，复用与原笔记及要求匹配的复习稿。已保存分镜可“重新渲染”，无需再次调用模型。修改原笔记后不能复用旧稿。

## 验证范围

已在本机完成当前 v1.6.15 定制版前端构建、笔记视频接口/结构校验测试、DeepSeek 真实分镜调用、42秒和48秒示例的本地渲染、桌面/手机入口、播放、下载与刷新后的持久化检查。公开分发包另检查哈希、补丁适用性和密钥泄漏。

这些结果不代表所有模型输出都正确，也不等同于在另一台全新 Windows 电脑上完成全新安装验收。复习内容可在中间稿及分镜依据中核对。
