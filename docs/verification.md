本记录由实际安装实例测试整理；不含私人会话地址、课程标识、账号凭据或学习数据库。

## DeepTutor

- 健康接口正常；项目自身调用模块获得真实 API 回答。
- 网页问答：二进制 `10=2`、`11=3`，内容正确。
- 回答练习 `01=1`、两位最大值为3，收到正确反馈和下一步文字编码建议。
- 正式“精通之路”生成两个知识点，经 Mastery Profile / Build 工具保存路线。
- 第一个知识点生成讲解与选择题，经 Mastery Quiz / Grade 接收答案并判对。

### 内容局限

选项随机重排后，解析仍可能引用旧字母；本次正确选项D判对，但说明错误地引用D为错误选项。这个问题未修复，不能当作全部判分逻辑都正确。

生成文本用“比特是两态装置”作类比，严格说bit是信息量单位/二进制位，不等同于具体硬件。灯的通断同样只是入门类比，不是精确电路模型。

第一次回答因浏览器旧偏好用了英文。重新选择中文并刷新后，后续中文问答和路线正常。浏览器整页翻译曾改写页面术语，检查内容应参考原文。
