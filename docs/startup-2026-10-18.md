# 2026-10-18 启动修复与新版运行方式

本次现有安装实测：Windows 11、Python 3.12.10、Node 24.22.0，DeepTutor v1.6.14、OpenMAIC v1.2.0。旧 `manage.ps1 Install` 仍固定 OpenMAIC v1.1.4；本更新没有把新版 PostgreSQL 安装与迁移自动化，也没有在全新电脑重跑完整安装。不要把下述运行脚本用于旧版 OpenMAIC。

## 适用条件

`scripts/runtime.ps1` 是针对已准备好的新版安装的独立入口，不替换旧安装脚本。安装根目录在仓库之外，布局要求：

- `DeepTutor/.venv/Scripts/python.exe` 和 `pythonw.exe`，带 Tkinter；DeepTutor 已完成源码安装。
- `DeepTutor/web/.next-deeptutor/standalone/server.js`，静态资源已按上游生产构建流程准备。
- `DeepTutor-runtime` 原配置和数据。
- `OpenMAIC` v1.2.0，依赖、`.next/BUILD_ID`、私人 `.env.local` 和数据库迁移已准备好。
- `tools/pgsql/bin` PostgreSQL 16 工具；`OpenMAIC-data/postgres` 已初始化，配置仅监听 `127.0.0.1:55432`。连接串由应用私人配置保存，脚本不生成或迁移密码。
- Node 在 PATH，或仅有一个 `tools/node-*-win-x64/node.exe`；多个版本时显式传 `-Node`。快捷方式启动时请确保 Node 在 PATH 或根目录下只有一个便携版本。
- Microsoft Edge。每个项目使用根目录下独立浏览器配置，原浏览器的课程不会自动迁移。

中文路径下 PostgreSQL 可能受系统编码影响。本机使用私人创建的 ASCII 路径目录联接指向安装根目录；其他机器需先验证数据库路径，脚本不会自动创建联接或搬动数据。

## 命令

```powershell
# Root 替换为实际已有安装，不能是本仓库
pwsh -NoProfile -File ./scripts/runtime.ps1 -Root 'E:\LearningSystems' -Action Check
pwsh -NoProfile -File ./scripts/runtime.ps1 -Root 'E:\LearningSystems' -Action Start -Project Both -Open
pwsh -NoProfile -File ./scripts/runtime.ps1 -Root 'E:\LearningSystems' -Action Restart
pwsh -NoProfile -File ./scripts/runtime.ps1 -Root 'E:\LearningSystems' -Action Stop
pwsh -NoProfile -File ./scripts/runtime.ps1 -Root 'E:\LearningSystems' -Action Shortcuts
```

快捷方式使用各项目源码中的官方图标，启动时显示中文进度小窗，网页打开后小窗立即关闭。后台不依附命令行窗口；关闭网页不停止服务。失败时保留错误窗口和日志入口。没有设置开机启动或 Windows 服务。

若桌面管理软件移动了快捷方式，用 `-ShortcutDirectory '实际已有目录'` 更新实际目录，避免在桌面重复创建。修改前备份到安装根目录 `backups`。启动器部署在安装根目录 `launcher`，之后移动整合仓库不会影响快捷方式。

DeepSeek 官网快捷方式继续使用：

```powershell
pwsh -NoProfile -File ./scripts/deepseek-shortcut.ps1 -Root 'E:\LearningSystems' -NoOpen
```

它指向官方 API 密钥网页，使用官网 favicon；与本地隐藏输入密钥窗口无关。

## 修复内容

- 对每个服务分别检查健康并复用，修复只有后端、没有前端的半启动状态。
- 启动直接运行生产包，不在双击时安装、构建或扫描源码。
- 每项目互斥锁避免连续双击创建重复服务。
- 记录 PID、进程创建时间和程序路径，停止前复核归属，拒绝占用端口的其他程序。
- 后端使用 `pythonw.exe`；PostgreSQL 控制进程使用独立隐藏控制台，避免关闭原命令行窗口导致数据库退出。
- 网页和后端绑定本机地址；健康请求绕过系统代理；日志写入安装根目录 `logs`。
- 保持原配置、数据库和学习目录，不自动升级或重新初始化。

## 本机验证与边界

本次实际安装完成：两网页、两次经用户授权的项目模型模块短文本调用、重启后笔记/文件夹保留、已有服务复用、前端缺失修复、重复启动、实际快捷方式启动，以及启动小窗退出后后台健康检查。未重复发送计费测试。

本机测得两项目健康复用约 0.3 秒，DeepTutor 单前端修复约 2.4 秒；完整重启一次约 17.4 秒，含数据库恢复的另一次约 37.9 秒。以上只作本机记录，不是性能保证。修复后检查没有遗留启动小窗或 Windows Terminal，服务均健康。

没有据此声称新版完整课程生成、媒体、搜索、多用户或所有功能通过。10 月 15 日旧版课程与练习验证见原测试记录，两次测试的版本和范围不同。可移植封装仅完成语法、只读健康检查及隔离目录快捷方式检查；全新机器安装仍待验证。

## 数据与费用

新版 OpenMAIC 包括 PostgreSQL、应用数据目录和浏览器站点数据，旧版仅备份浏览器课程的说明不能覆盖新版。停止服务后私人备份 `OpenMAIC-data`、原浏览器配置、`.env.local` 和 DeepTutor runtime；数据库宜另做 PostgreSQL 官方支持的逻辑备份。备份可能含密码和学习材料，不上传 GitHub。

脚本不读取或上传密钥，也不发起模型请求。网页发送问题或生成课程会计费，额外测试应事先确认范围。
