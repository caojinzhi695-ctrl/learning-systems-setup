# DeepTutor 固定模板总结笔记

这是本仓库的本地定制，基于官方 **DeepTutor v1.6.14**，不是上游官方自带功能。主页式输入区域配合可折叠的右侧收集栏，避免笔记正文占满中间屏幕。

## 安装

首次使用 README 中的 `Install` 命令，会自动获取官方源码并应用本定制、安装依赖及构建前端。

已通过本仓库安装原版 v1.6.14 的用户，可在更新本仓库后执行：

```powershell
pwsh -NoProfile -File ./scripts/manage.ps1 -Action CustomizeNotes -Root 'E:\LearningSystems'
pwsh -NoProfile -File ./scripts/manage.ps1 -Action Start -Project DeepTutor -Root 'E:\LearningSystems'
```

`CustomizeNotes` 会先停止 DeepTutor，修改前备份需要打补丁的代码；不会覆盖模型配置或学习数据。仅支持包内清单指定的上游提交，文件冲突会停止并提示手动合并。首次转换为源码安装需要下载前端依赖并构建，可能耗时数分钟。安装脚本不会发起模型请求。

需要先检查兼容性而不修改文件时：

```powershell
python ./scripts/prepare-notes.py --source 'E:\LearningSystems\DeepTutor' --dry-run
```

## 使用

打开 <http://127.0.0.1:3782/summary-notes>，或点击左侧“总结笔记”。

1. 点击顶部“＋”新建笔记聊天，或在下拉框选择已有聊天。
2. 在欢迎语下方粘贴阅读材料、已有笔记或转写；回形针可导入 TXT/Markdown。
3. 点击“↑”发送。三个快捷入口只填写整理要求，不自动发送。
4. 程序先生成完整文字笔记，再在本机按固定模板生成单文件 HTML。
5. 右侧“收集栏”保存当前聊天每次输入的材料和结果，可整体收起；每条材料、文字笔记和网页预览也可独立折叠。
6. 在结果卡片下载文字笔记和 HTML。HTML 可离线打开，不需要公开部署。
7. 继续输入修改要求可生成新的完整版本，旧结果保留。

固定六章：阅读概览、核心观点与论证、关键概念与方法、结构化思维导图、阅读思考、实践与复习。规则强调忠实材料、标注范围、区分原文与延伸思考、不编造作者和位置。

HTML 沿用随包固定模板的配色、章节卡片、导航和目录。思维导图通常为桌面两列四卡片、手机单列；材料不足时不强凑分支。表格可横向滚动。

## 模型与范围

- 使用 DeepTutor 当前配置的文字模型，无需另填一份密钥。本机已用 DeepSeek 验证一轮。
- 本定制按照维护者选择，点击发送即确认本次模型用量，不再显示逐次 API 勾选框；**发送材料和后续修改仍会产生供应商 API 费用**。HTML 转换不额外调用模型。
- 请求发送当前笔记聊天的材料和已有完整笔记。敏感材料请先确认供应商数据政策，不要直接提交凭据。
- 单次最多 4 万字符，累计上下文超过 6 万字符会拒绝发送，不静默裁剪。
- 本版直接处理文字。PDF、音视频原文件需先提取正文、字幕或转写；不能声称已实际听音或核对画面。
- 回答截断、缺章或导图格式错误会保留草稿并明确失败，不假装交付完整网页；不自动重复发送。
- 未发送的输入框草稿不持久化。网络中断后先重新打开聊天检查结果，避免重复提交。
- 自动检查完成状态与结构不能保证模型内容全部忠实，正式使用需对照原材料复核。

## 文件、备份与更新

```text
安装根目录/
├── DeepTutor/deeptutor/services/summary_notes/assets/
│   ├── instructions.md       # 固定文字笔记规则
│   └── note-template.html    # 固定网页模板
└── DeepTutor-runtime/data/user/workspace/summary_notes/
    └── 聊天ID/
        ├── session.json     # 材料、历史结果
        ├── 请求ID.md
        └── 请求ID.html
```

停止服务后备份整个 `DeepTutor-runtime/data`。不要把上述运行数据、下载的个人笔记或配置提交到公开仓库。

升级官方 DeepTutor 前先备份数据和定制代码。本包严格限定 v1.6.14；其他版本需重新适配，不能直接强套补丁。源码安装不要被普通 `pip install -U deeptutor` 意外替换。

## 印象笔记导出（0.3.0）

每份已完成笔记标题下方有三个按钮：下载文字笔记、下载 HTML 网页、导出到印象笔记。电脑并排、手机竖排，按钮高度至少 44px。下载 ENEX 后在印象笔记桌面客户端导入，顶部包含普通 HTML 文件附件，正文为可编辑标题/列表/表格。重复导入会新增记录。附件保留完整模板，实际客户端打开效果仍需用户验证。

已有 v1.6.14 安装先停止并备份，拉取整合仓库更新后运行 CustomizeNotes。仅允许自动升级清单中已知旧版的精确哈希文件，升级前保存代码备份；用户自行改过的文件仍会拒绝覆盖并提示合并。无需改模型设置或重生成笔记，无新增依赖或数据迁移。新安装直接包含此功能。
