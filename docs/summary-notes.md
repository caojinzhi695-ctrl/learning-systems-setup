# DeepTutor 固定模板总结笔记

这是本仓库的本地定制，基于官方 **DeepTutor v1.6.14**，不是上游官方自带功能。主页式输入区域配合可折叠的右侧收集栏，避免笔记正文占满中间屏幕。

## 安装

首次使用 README 中的 `Install` 命令，会自动获取官方源码并应用本定制、安装依赖及构建前端。

已通过本仓库安装原版 v1.6.14 的用户，可在更新本仓库后执行：

```powershell
pwsh -NoProfile -File ./scripts/manage.ps1 -Action CustomizeNotes -Root 'E:\LearningSystems'
pwsh -NoProfile -File ./scripts/manage.ps1 -Action Start -Project DeepTutor -Root 'E:\LearningSystems'
```

`CustomizeNotes` 会先停止 DeepTutor，修改前备份需要打补丁的代码；不会覆盖模型配置或学习数据。仅支持包内清单指定的上游提交，文件冲突会停止并提示手动合并。首次转换为源码安装需要下载前端依赖并构建，可能耗时数分钟。安装脚本不会发起模型请求。

需要先检查兼容性而不修改文件时：

```powershell
python ./scripts/prepare-notes.py --source 'E:\LearningSystems\DeepTutor' --dry-run
```

## 使用

打开 <http://127.0.0.1:3782/summary-notes>，或点击左侧“总结笔记”。

1. 点击顶部“＋”新建笔记聊天，或在下拉框选择已有聊天。
2. 在欢迎语下方粘贴材料，或将文件拖入输入框；回形针也支持多选文件。提取后可检查、编辑，再手动发送。
3. 点击“↑”发送。三个快捷入口只填写整理要求，不自动发送。
4. 程序先生成完整文字笔记，再在本机按固定模板生成单文件 HTML。
5. 右侧“收集栏”保存每次材料和结果，最新记录在最上方；每条材料、文字笔记和网页可折叠。点击“删除笔记”并确认后，删除该条材料、结果及导出文件，不影响其他记录。
6. 在结果卡片点击“复制笔记”复制完整文字，或下载 HTML。HTML 可离线打开，不需要公开部署。
7. 继续输入修改要求可生成新的完整版本，旧结果保留。

固定六章：阅读概览、核心观点与论证、关键概念与方法、结构化思维导图、阅读思考、实践与复习。规则强调忠实材料、标注范围、区分原文与延伸思考、不编造作者和位置。

HTML 沿用随包固定模板的配色、章节卡片、导航和目录。思维导图通常为桌面两列四卡片、手机单列；材料不足时不强凑分支。表格可横向滚动。

## 模型与范围

- 使用 DeepTutor 当前配置的文字模型，无需另填一份密钥。本机已用 DeepSeek 验证一轮。
- 本定制按照维护者选择，点击发送即确认本次模型用量，不再显示逐次 API 勾选框；**发送材料和后续修改仍会产生供应商 API 费用**。HTML 转换不额外调用模型。
- 请求只发送最近一版成功笔记对应输入、该版完整笔记及本次输入，历史记录仍保留，不逐次叠加旧版本。敏感材料请先确认供应商数据政策，不要直接提交凭据。
- 单次最多 4 万字符，上述有效上下文超过 6 万字符会拒绝发送，不静默裁剪。
- 支持 PDF、DOCX、PPTX、XLSX、TXT、MD、CSV、SRT、VTT，以及 MP3、WAV、M4A、AAC、FLAC、OGG、MP4、WEBM。旧版 DOC/PPT/XLS 请先转换格式；图片和扫描 PDF 需先做 OCR，本版不会读取画面文字。
- 单个文件最多 50MB，多文件提取内容追加到已有输入；合并后超过4万字符则拒绝填入，保留原输入，不截断、不自动调用付费模型。
- 音视频须配置本地拾页转写引擎，最长60分钟、处理超时10分钟；使用临时文件，转写后清理，不永久保存媒体。模型识别结果需要核对。
- DeepSeek 总结请求关闭思考模式，输出预算 16000 tokens、总等待10分钟；失败仍保留收到的草稿，不自动重复计费。
- 回答截断、缺章或导图格式错误会保留草稿并明确失败，不假装交付完整网页；不自动重复发送。
- 未发送的输入框草稿不持久化。网络中断后先重新打开聊天检查结果，避免重复提交。
- 自动检查完成状态与结构不能保证模型内容全部忠实，正式使用需对照原材料复核。

## 文件、备份与更新

### 文件提取与本机转写配置

文字/Office 提取使用 PyMuPDF、python-docx、python-pptx、openpyxl，上传接口需要 python-multipart。本机已有依赖完成验证；若新安装缺少包，在 DeepTutor 虚拟环境安装对应依赖后重启。

音视频导入不会调用云端语音 API，需要先安装拾页 Content Shelf 抓取引擎与 base 模型，再通过环境变量 `SUMMARY_NOTES_ASR_ROOT` 指向其项目根目录；也可在 DeepTutor 运行目录的 `data/user/settings/summary_notes_asr.json` 私下保存：

```json
{"root":"E:/YourApps/content-shelf"}
```

运行配置不随源码分发。音视频功能目前依赖 Windows 的 `data/crawler-python/Scripts/python.exe`，其他系统需另行适配，不能视为跨平台已验证。

## 印象笔记导出（0.3.0）

每份已完成笔记标题下方有三个按钮：复制笔记、下载 HTML 网页、导出到印象笔记。电脑并排、手机竖排，按钮高度至少 44px。下载 ENEX 后在印象笔记桌面客户端导入，顶部包含普通 HTML 文件附件，正文为可编辑标题/列表/表格。重复导入会新增记录。附件保留完整模板，实际客户端打开效果仍需用户验证。

已有 v1.6.14 安装先停止并备份，拉取整合仓库更新后运行 CustomizeNotes。仅允许自动升级清单中已知旧版的精确哈希文件，升级前保存代码备份；用户自行改过的文件仍会拒绝覆盖并提示合并。无需改模型设置或重生成笔记，无新增依赖或数据迁移。新安装直接包含此功能。


## 0.5.0 日常使用与变化

- 新笔记显示在收集栏最上方；点击“复制笔记”复制完整Markdown文字，成功后显示“已复制”。HTML、ENEX继续下载。
- 来源说明使用简短一段，通常1—2句，交代实际材料、范围和必要限制。
- 只有第二章的“解释与依据”采用简洁分点、案例过程与数据对照；其他模块保持原规则。
- 导图多于四分支时，额外分支合放在第四张卡片，不删除观点。
- 密钥认证失败会明确提示401；在本机设置更新密钥，勿发送或提交到公开仓库。此类修复不能替代有效密钥。
- 同一聊天修改时仅携带最近成功版本及其对应输入；如需较早材料细节，请重新粘贴相关原文，不能假定所有早期原文仍传给模型。
- 更新提示词仅影响后续生成；已有笔记不会自动重写。更新不自动重发失败请求。

更新方式：停止服务并备份数据，拉取本仓库后沿用上方 `CustomizeNotes` 步骤。升级器仅接受清单中的已知旧版文件；自行改动过的代码须人工合并。新电脑安装及印象笔记客户端导入仍未在本次重新验证。
