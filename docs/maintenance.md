# 备份、更新和卸载

## 备份

DeepTutor：停止服务后，私人复制整个 `DeepTutor-runtime/data`。它包含配置、聊天与学习状态；以后填入的密钥也可能在其中，不能上传公开仓库。

OpenMAIC：在原浏览器中导出每个重要课程的课堂ZIP，保存到安装根目录的 `OpenMAIC-data/exports`。当前课程与学习进度由浏览器IndexedDB保存；清除站点数据、换浏览器或更改主机名/端口，可能看到空课程列表。

课程ZIP是否包含所有个人运行状态未验证；不要用ZIP备份替代对学习进度的额外记录。仅复制源码不会保存浏览器课程。

## 更新

1. 查看两个官方项目 Releases 和迁移说明，选择非预发布版本。
2. 停止服务，备份数据及原配置。
3. DeepTutor在独立虚拟环境中安装明确版本，保持同一runtime home。不要删除数据重新安装。
4. OpenMAIC建议新目录准备新稳定版本，迁移私人配置，安装依赖并构建；保持原访问地址和浏览器。
5. 阅读并重新评估 `scripts/prepare.py` 的版本限定修改；官方修复后应移除对应本地兼容代码，不盲目套补丁。
6. 验证网页、一次小问答、学习记录保存；调用模型会计费。

总结笔记定制使用源码安装，并严格限定 DeepTutor v1.6.14。升级前先保留定制补丁与数据；其他版本不能直接运行 `CustomizeNotes` 强套。笔记数据位于 `DeepTutor-runtime/data/user/workspace/summary_notes`，也包含在完整 data 备份中。详见 [总结笔记维护说明](summary-notes.md)。

本仓库不会自动跟踪开发分支或自动升级应用。修改端口后同时更新启动命令，并注意OpenMAIC浏览器数据按站点隔离。

## 卸载而保留数据

先停止服务并完成私人备份。可以移除DeepTutor参考代码和`.venv`，保留`DeepTutor-runtime`；移除OpenMAIC程序与依赖前导出课程，保留原浏览器站点数据和ZIP。

不要卸载其他软件正在用的Python、Node、Git，也不要删除浏览器整个用户配置。

本仓库本身只有脚本和说明，删除此仓库不应删除独立安装根目录。
