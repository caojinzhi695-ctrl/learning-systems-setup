# 第一次学习

## 准备

先安装、配置 API，再启动服务。没有配置模型时，页面能打开但不能生成内容。

DeepTutor：进入设置 → 常规，将“界面语言”选为中文，“模型输出语言”选为简体中文，应用更改并刷新。语言偏好在每个浏览器独立保存。

OpenMAIC：右上角语言菜单选择“简体中文”。模型选择应显示 DeepSeek / deepseek-flash。

不要叠加浏览器整页自动翻译，它可能把代码、术语甚至原始中文改写成错误表达。

## DeepTutor

1. 打开 <http://127.0.0.1:3782>。
2. 在聊天中先提一个简短问题，确认模型正常回答。
3. 进入“个性化学习”→“精通之路”→新建目标。
4. 输入：

   > 零基础理解计算机如何用0和1表示信息。只需两个知识点：比特与两种状态、两位二进制。简体中文，每点一个简短练习，不搜索、不生成媒体。

5. 选择工作区；没有资料时可以不附资料，与导师商定大纲。
6. 回答学习时长、练习形式等澄清问题；审阅大纲，再开始学习。
7. 从第一点开始，阅读、答题、查看反馈。不要把“一题答对”误认为整条路线已经掌握；门槛可能要求更多证据。
8. 关闭后再次进入同一目标，检查记录能否继续。

遇到问题可要求换例子、先提示不直接给答案，或申请复核判分。

## OpenMAIC

1. 打开 <http://127.0.0.1:3001>，选中 DeepSeek 模型。
2. 输入：

   > 为零基础学习者生成“计算机如何用0和1表示信息”的短课程。简体中文，仅两页文字课件和一道选择题；不使用图片、视频、语音、搜索和深度交互。

3. 首次先关闭“深度交互”，额外媒体服务保持未配置。
4. 点击进入课堂，等待大纲、角色、页面与讲解生成。每个阶段都可能调用 API。
5. 阅读两页课件；进入随堂测验，选择答案并提交，查看报告。
6. 返回首页，从“最近学习”重新打开。
7. 用右上角导出菜单选择“导出课堂 ZIP”，私人保存。

文字讲稿生成与语音播放是不同功能：本方案只验证前者。

## 控制费用

课程先短后长；不要连续重复生成失败任务；保留有用的课程和路线。长对话、工具调用与推理也会产生用量，页面上的 token 数不等于实际人民币费用，实际账单以供应商为准。
